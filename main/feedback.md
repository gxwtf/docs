# 广学五题坊反馈指南

感谢你愿意花时间向我们反馈问题与建议。为了让每一条反馈都能被准确理解、快速处理，请在提交前阅读本指南。

本指南仅供参考，在实际反馈过程中，你可以不使用指南中的格式，但是请把你的需求表达清楚。  

> 请注意：目前反馈系统**只能提交纯文本**，且**没有反馈记录、反馈编号和状态查询功能**。提交后无法在站内查看历史反馈或处理进度。如希望收到回复，请务必填写有效联系方式，并自行保存一份反馈内容。

## 一、反馈系统可以处理什么？

欢迎提交以下类型的内容：

- **功能异常**：按钮无反应、页面报错、数据不同步、无法登录等。
- **体验问题**：流程复杂、界面难用、文字错误、加载过慢等。
- **功能建议**：希望新增功能、优化现有功能、改进交互方式。
- **内容问题**：错误信息、垃圾广告、侵权内容、违规内容等。
- **账号注册申请**：部分子系统的账号需要管理员人工注册，你可以通过反馈系统提交申请。
- **子系统账号/权限问题**：账号无法登录、需要重置密码、需要开通权限、加入白名单等。主站账号的问题建议直接前往 **[账号中心](https://account.gxwtf.cn/)** 解决。
- **其他与本站相关的问题**。

以下情况请走专门渠道：

- 账号被盗、支付异常、订单问题、紧急安全事件：请 **[联系我们](/main/manual.md#联系我们)**。
- 法律投诉、版权申诉：请发送至 **[gxwtf@foxmail.com](mailto:gxwtf@foxmail.com)**。
- 与本站无关的问题：反馈系统可能无法受理。

## 二、如何提交反馈？

1. 登录广学五题坊。
2. 进入反馈入口：**[主页顶栏 > 反馈](https://gxwtf.cn/feedback/new)**。
3. 在标题或正文开头写明反馈类型，例如：功能异常、体验问题、功能建议、内容举报、账号注册申请、其他。
4. 填写标题和详细描述。
5. 如需提供图片、截图或录屏，请先上传到公共图床或网盘，再把链接粘贴到反馈正文中。反馈系统本身不能上传附件。
6. 留下联系方式。由于系统没有反馈记录，如希望我们回复，请填写有效邮箱或手机号。
7. 提交前请自行复制或截图保存反馈内容。提交后不会生成反馈编号，也无法在站内查询进度。

## 三、纯文本反馈的图片说明：请使用公共图床

由于反馈系统目前只能提交纯文本，无法直接上传图片、截图或录屏。如果你需要提供图片证据，可以：

1. 先将图片上传到可公开访问的公共图床或网盘。常见公共图床包括 sm.ms、Imgur、路过图床等，具体以你能正常访问为准。
2. 上传后获取图片链接或分享链接。
3. 将链接粘贴到反馈正文中，并简单说明每张图对应什么内容。
4. 如果使用网盘，请确保链接可访问，不要设置过期时间；如有提取码，请一并写在反馈中。
5. 如果无法使用图床，也可以用文字尽量详细地描述报错内容、按钮文字、页面提示等。

**隐私提醒：**

- 公共图床链接可能是公开的，上传前请务必打码手机号、邮箱、身份证号、地址、订单号、账号等敏感信息。
- 不要上传包含密码、验证码、支付信息的截图。
- 录屏也请上传到可访问的网盘，并检查其中是否包含隐私信息。
- 如涉及他人隐私，请先获得允许或进行打码处理。

## 四、特殊类别反馈怎么提交？

### 1. 账号注册申请

如果某个子系统的账号需要管理员注册，或者你需要帮无法使用邮箱的同学注册广学账号，你可以通过反馈系统提交注册申请。

**目前可以注册以下子系统的账号：广学博客（blog.gxwtf.cn）、广学相册（photos.gxwtf.cn）、广学五题坊AI（ai.gxwtf.cn）。**

请在反馈中写明：

- 申请系统名称或入口链接（如果是主站账号，请填写“广学五题坊”或“广学账号”）；
- 希望使用的账号名称；
- 初始密码。**如果不写，管理员将默认设置为 `123456`**；
- 你的联系方式；
- 申请理由或备注；
- 是否需要额外权限。

可复制模板：

```text
【反馈类型】账号注册申请
【系统】例如：广学博客
【账号名称】希望使用的账号名
【初始密码】留空则默认 123456；也可填写临时密码
【联系方式】邮箱 / 手机号
【申请理由】
【备注】
```

注意事项：

- 请不要填写你在其他网站正在使用的重要密码。
- 反馈系统为纯文本传输，密码存在被他人看到的风险。建议留空使用默认密码，或填写一个临时密码。
- 如果留空，管理员会默认设置为 `123456`。首次登录后请尽快修改密码。
- 如果该子系统不支持自行修改密码，请在申请中说明，或登录后再次反馈请求改密。
- 账号名称可能已被占用，管理员可能会与你联系调整。
- 管理员会人工处理，但不保证立即开通。一般会在 1—3 个工作日内查看，复杂情况可能需要 7 个工作日或更久。

### 2. 子系统账号或权限问题

如果你已有子系统账号，但遇到以下问题，也可以提交反馈：

- 忘记密码，需要重置；
- 账号无法登录；
- 需要开通某个功能权限；
- 需要加入白名单；
- 需要修改绑定信息。

请尽量提供：子系统名称、账号名称、问题现象、出现时间、联系方式。**不要提供你的重要密码、验证码或支付信息。**

### 3. 内容举报

请提供具体链接、截图链接、违规类型、发生时间。如涉及他人隐私，请打码处理。

## 五、怎样写一条“有效反馈”？

一条好的反馈通常包含以下信息：

- **发生了什么**：一句话概括问题。
- **在哪里发生**：页面名称、链接、功能模块。
- **怎么发生的**：按顺序写出操作步骤。
- **你预期是什么**：原本应该出现什么结果。
- **实际是什么**：实际出现了什么结果。
- **出现频率**：每次必现、偶尔出现、仅出现一次。
- **环境信息**：设备型号、操作系统、浏览器/App 版本。
- **证据链接**：图片、录屏、报错文字。由于不能上传附件，请提供公共图床或网盘链接。
- **联系方式**：便于我们进一步核实。由于没有反馈记录，强烈建议填写。

### 可复制模板

```text
【反馈类型】功能异常 / 体验问题 / 功能建议 / 内容举报 / 子系统账号注册申请 / 其他
【一句话标题】例如：Chrome 在错题本页面点击“导出”无反应
【问题描述或申请说明】
【发生位置】页面名称或链接
【操作步骤】
1.
2.
3.
【预期结果】
【实际结果】
【出现频率】每次 / 偶尔 / 仅一次
【环境信息】设备、系统、浏览器或 App 版本
【图片/录屏链接】如无可填“无”
【联系方式】邮箱 / 手机号
【备注】
```

## 六、示例

> 【环境】Windows 11，Chrome 122，账号 test  
> 【图片链接】https://gxwtf.cn/test.png （截图已打码）  
> 【联系方式】test@gxwtf.cn

**账号注册申请示例：**

> 【反馈类型】账号注册申请  
> 【系统】广学博客  
> 【账号名称】小广  
> 【初始密码】114514  
> 【联系方式】test@gxwtf.cn

> “网站太垃圾了，赶紧修。”

这类反馈缺少具体位置、操作步骤和现象，我们很难定位问题。

## 七、请避免这些行为

- 人身攻击、辱骂、威胁或歧视性言论。
- 重复刷屏、恶意提交大量相同反馈。
- 提交违法、色情、暴力、广告或与本站无关的内容。
- 除“账号注册申请”外，在反馈中填写密码、验证码、银行卡号、身份证号等敏感信息。
- 即使在账号注册申请中，也不要填写你在其他网站的重要密码。
- 未经允许上传包含他人隐私的截图或信息。
- 将含隐私信息的截图上传到公开图床而不打码。
- 要求“立即处理”或“必须按我的方案修改”。我们会评估，但无法承诺全部采纳。

## 八、处理流程与时间

提交流程：

**提交反馈 → 人工阅读分类 → 核实/处理 → 通过联系方式回复或站内通知 → 关闭**

一般情况下，我们会在 **1—3 个工作日**内查看；复杂问题可能需要 **7 个工作日或更久**。紧急问题请直接[联系我们](/main/manual.md#联系我们)，而不是仅提交反馈。

由于目前反馈系统**没有反馈记录和状态查询功能**，你无法在站内查看处理进度。请务必保留联系方式，并自行保存提交内容。如需补充信息，可以重新提交一条反馈，并在标题中注明“补充反馈：原反馈标题 + 提交时间”。但请注意，系统无法自动关联两条反馈。

## 九、隐私与安全

我们仅在处理反馈所必需的范围内使用你提供的信息。未经你的同意，我们不会公开你的个人信息。

一般情况下，请不要在反馈中提交任何密码、验证码、支付信息或身份证件信息。

唯一例外是“子系统账号注册申请”：你可以在申请中填写临时初始密码，或留空由管理员默认设置为 `123456`。请不要使用你在其他网站的重要密码。首次登录后，请尽快修改密码。

如果你使用公共图床或网盘提供图片、录屏，请注意链接可能被他人访问，上传前请打码处理敏感信息。

## 十、常见问题

**Q：提交后没有回复怎么办？**  
A：目前系统没有反馈记录和反馈编号，无法在站内查看状态。如果超过 7 个工作日仍未收到回复，请通过邮箱联系我们，并在邮件中附上反馈标题、提交时间、账号和反馈内容大意。

**Q：可以匿名反馈吗？**  
A：目前不可以。为了防止反馈系统被滥用，请先登录账号再反馈。如果出现无法登录的情况，请直接向我们发送邮件。

**Q：所有建议都会被采纳吗？**  
A：每条反馈我们都会阅读和评估，但是否实现会综合考虑产品规划、技术成本和用户影响。

**Q：内容举报需要提供什么？**  
A：请提供具体链接、截图链接、违规类型、发生时间。如涉及他人隐私，请打码处理。

**Q：反馈系统能上传图片吗？**  
A：不能。目前只能提交纯文本。如需提供图片，请先上传到公共图床或网盘，再把链接粘贴到反馈中。

**Q：子系统账号怎么注册？**  
A：提交“账号注册申请”，写明申请子系统、账号名称、初始密码和联系方式。如果不写密码，管理员会默认设置为 `123456`。首次登录后请尽快修改。

**Q：为什么没有反馈编号？**  
A：目前反馈系统比较简陋，只能提交纯文本，没有反馈记录功能。请自行保存反馈内容，并填写有效联系方式。

感谢你的反馈。真实、具体、文明的反馈，会帮助我们更快解决问题，也能让广学五题坊变得更好。
