# 广学英语

[广学英语](https://english.gxwtf.cn/)是[广学五题坊](https://gxwtf.cn/)旗下的一款英语学习网站，主打「**用 AI 把生词本变成会出题的私教**」。

它不是又一个「只考选择释义」的背单词软件。你可以把课本、试卷、阅读材料里碰到的生词一个个（或一次性批量）收进自己的单词本，然后让 AI 围绕这些词自动出选择题、填空题、翻译题，做完还会给你逐题点评，并按照遗忘规律安排下一次复习。

## 它解决了什么问题

- **只会考释义**：普通软件只是「英文选中文」，而广学英语能把单词出成**选词填空、翻译句子**等多种真正需要用脑的题型。
- **一词多义不好处理**：同一个单词往往有好几个意思。广学英语允许你**只勾选自己不会的那几个释义**，AI 也只针对这些释义出题。
- **自定义词库麻烦**：支持随意增删单词、批量导入、拍照识词、打标签、在多个单词本之间复制移动。

## 主要功能一览

| 功能 | 一句话说明 |
| --- | --- |
| 单词本 | 像文件夹一样管理生词，支持多个单词本、批量操作、搜索筛选、导出 PDF |
| 系统单词本 | 一键把管理员准备好的「高考 3500 词」等词库复制进自己的单词本 |
| AI 复习 | 把选中的单词生成 7 种练习题，做完有 AI 点评 |
| 遗忘曲线 | 按「快忘了」和「老出错」自动安排复习顺序，不用自己算时间 |
| 拍照识词 | 上传用荧光笔高亮的纸质资料照片，自动识别生词并入库 |
| 作文积累 | 收集好词好句，可以用「AI 找词」从作文里挑出高级词汇。**该功能计划从本项目分离，暂无详细文档** |
| 广学账号 | 用广学账号登录，一次登录全站通行 |

## 三分钟上手

1. 打开 [english.gxwtf.cn](https://english.gxwtf.cn/)，点击「**使用广学账号登录**」并登录。
2. 进入「**单词本**」，点击「**新建单词本**」。想省事可以直接导入「高考 3500 词」。
3. 进入单词本，点击「**添加单词**」，输入单词 → 查询 → 勾选自己不会的释义 → 保存。
4. 回到首页或单词本，选中单词后点击「**AI 复习**」，挑一种题型生成题目。
5. 到「**题目**」页作答，提交后可看批改结果和 AI 点评。
6. 过一两天再回来，首页会告诉你哪些词「该复习了」，点「**一键复习**」即可。

- **网页版直接可用**，无需安装 App。
- **数据保存在云端账号里**，换设备登录同一个广学账号即可看到自己的单词本。
