# 作文积累本

[作文积累本](https://writing.gxwtf.cn/)是[广学五题坊](https://gxwtf.cn/)旗下的作文积累工具：把阅读、范文、试卷里遇到的好句好段收进自己的积累本，打上标签，随时检索，还能用 AI 从作文里挑出好词，最后一键导出成可打印的 PDF。

> 作文积累本原先是「广学英语」里的一个功能，2026 年 10 月起独立为单独网站。原来的 [english.gxwtf.cn/writing](https://english.gxwtf.cn/writing) 会**自动跳转**到新网站，历史数据也已一并迁移，无需重新录入。

## 主要功能

| 功能 | 一句话说明 |
| --- | --- |
| 作文积累 | 记录作文内容与备注，随时编辑、删除 |
| 标签 | 自己定义标签（可改颜色），按标签筛选（「全部满足」或「任一满足」） |
| 设置 | 右上角「设置」里统一管理标签（新建 / 改名 / 换色 / 删除） |
| 搜索与排序 | 按内容/备注搜索，按首字母或时间排序 |
| 批量操作 | 全选 / 区间选择，批量打标签、批量删除 |
| AI 找词 | 让 AI 从选中的作文里挑出替换词、高考核心词、写作高级表达或外刊词汇 |
| 导出 PDF | 选中若干条（或当前筛选结果）导出 A4 双栏 PDF，方便打印背诵 |
| 广学账号 | 用广学账号登录，与广坊其他站点通用 |

## 快速上手

1. 打开 [writing.gxwtf.cn](https://writing.gxwtf.cn/)，点击「**使用广学账号登录**」。
2. 点击右上角「**添加积累**」，输入作文内容（必填）和备注（可选），选择标签后保存。
3. 在列表里点击卡片即可选中；选中后可用「**批量操作**」设置标签、导出 PDF 或删除。
4. 想从作文里挑好词：先选中作文，再点「**批量操作 → AI 找词**」，选择目标难度，稍等片刻即可看到结果，点「**复制单词列表**」后到广学英语的「批量添加单词」里粘贴即可。
5. 点击「**导出 PDF**」可以把选中的积累导出为可打印的 PDF。

## 标签怎么用

标签是你自己的分类方式，常见用法：

- 按来源分：范文、试卷、阅读材料、课本；
- 按主题分：环保、科技、校园生活、传统文化；
- 按用途分：开头结尾、高级词汇、过渡句、万能句型。

管理标签有两个入口，打开的都是同一个「标签管理」窗口：

- 点右上角「**设置**」→「**标签管理**」，专门整理标签；
- 或者在「添加积累」/「批量设置标签」里点「**标签管理**」，边打标签边改。

在窗口里可以新建、改名、换色或删除标签；删除前会告诉你这个标签被多少条积累用着。

> 与广学英语的标签体系**相互独立**：这里的标签只用于作文积累，不会影响广学英语的单词标签。

## 添加到手机主屏幕

作文积累本支持像 App 一样装到手机桌面，打开即全屏，不用再输网址：

- **iPhone / iPad（Safari）**：打开 [writing.gxwtf.cn](https://writing.gxwtf.cn/)，页面底部会提示
  点击「分享」→「添加到主屏幕」；也可以手动点 Safari 底部的分享按钮操作。
- **Android（Chrome / Edge 等）**：打开站点后点页面底部提示里的「**安装**」，或从浏览器菜单选「安装应用」。

装好后桌面图标是「笔记本 + 笔」的红色小标志，点开直接进入积累本。

## 常见问题

**Q：以前的作文积累还在吗？**
A：在。独立时历史数据已完整迁移，登录后即可看到原来的积累。

**Q：AI 找词提取出来的单词会自动进单词本吗？**
A：不会。独立后作文积累本不再直接写入广学英语单词本，需要你复制结果后到广学英语手动批量添加。

**Q：以后会支持语文作文吗？**
A：会。数据层已预留学科字段，后续版本将支持语文作文积累。

> 面向开发者的技术文档见[《作文积累本开发文档》](https://dev.gxwtf.cn/#/writing/)。
